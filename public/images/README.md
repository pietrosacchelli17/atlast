# Images

Drop real photographs here and they replace the generated placeholders automatically.
The path is set by each item's `image` field in `src/data/*`.

- `places/<place-slug>.jpg`
- `destinations/<destination-slug>.jpg`
- `guides/<guide-slug>.jpg`
- `journal/<article-slug>.jpg`
- `about.jpg`

Recommended: landscape 3:2 or 4:3, 2000px wide, JPEG. Credit photographers in captions; no photo credits are invented in this prototype.
